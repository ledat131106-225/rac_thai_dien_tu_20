# EcoRecy — Website giới thiệu thiết bị tái chế rác thải điện tử

Website tĩnh HTML/CSS/JS phục vụ đề án đưa thiết bị tái chế rác thải điện tử quy mô nhỏ ra thị trường qua thương mại điện tử.

## Chạy local
Mở `index.html` bằng trình duyệt.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload `index.html`, `style.css`, `script.js`.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/root`.
6. Save và chờ GitHub tạo website.

## Lưu ý
Tên EcoRecy, thông số và nội dung là mẫu minh họa. Hãy thay bằng tên thương hiệu, thông số kỹ thuật, giá bán, ảnh sản phẩm và thông tin liên hệ thực tế trước khi công bố.
